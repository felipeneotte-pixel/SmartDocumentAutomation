## 📌 Overview

SmartDocumentAutomation is a desktop application developed in Python to automate document processing workflows.

The application scans PDF files, extracts text (including scanned documents using OCR), classifies documents, organizes them into folders, and generates Excel reports with the extracted information.

This project demonstrates skills in:

- Python
- File Automation
- OCR
- PDF Processing
- Data Extraction
- Excel Automation
- GUI Development
- Logging
- Clean Code

---

## ✨ Features

- 📂 Scan folders for PDF files
- 📄 Extract text from digital PDFs
- 🔍 OCR support for scanned documents
- 🗂 Automatic document classification
- ✏️ Automatic file renaming
- 📁 Automatic folder organization
- 📊 Excel report generation
- 📝 Detailed logging system
- 🖥 Modern graphical interface

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/SmartDocumentAutomation.git
```

Go to the project folder:

```bash
cd SmartDocumentAutomation
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
